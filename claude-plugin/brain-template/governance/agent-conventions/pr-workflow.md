# Pull request workflow

1. Read the relevant Brain context and source evidence.
2. Create a focused branch.
3. Add or update one durable concept.
4. Run `./lint-brain.sh`.
5. Open a pull request explaining source, change, privacy classification and expected value.
6. Merge only after the configured human or automated gate passes.

Protected paths include company identity, principles, privacy, governance, agent permissions and writeback rules. These always require human review.
