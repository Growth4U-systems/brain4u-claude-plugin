# Brain4U

Private company brain initialized from the empty Brain4U template.

It combines four layers:

- `wiki/`: durable company knowledge following the LLM Wiki pattern.
- `skills/`, `agents/`, `commands/`, `hooks/`: reusable behavior and workflows inspired by GStack.
- `governance/`: rules for memory, privacy, review and writeback.
- `gbrain.yml`: read-only indexing contract for GBrain-compatible retrieval.

Start by completing `wiki/company/identity/README.md` and `wiki/company/principles/README.md`. Do not paste raw exports or credentials into this repository.
