# Remember

Confirm the content is durable, source it, classify privacy, deduplicate it and make the smallest authorized canonical change through the Brain write workflow. Use the memory helper for sourced decision and learning records; use reviewed pull requests for protected behavior and policy changes.

If the candidate comes from MemSearch, treat its Claude Haiku summary as a pointer to evidence rather than as an approved fact. Review the relevant source context, remove transient or private material and never copy `.memsearch/` or its index into the repository. Verify the helper's remote publication result, or obtain the required review, before treating the learning as canonical Brain memory.
