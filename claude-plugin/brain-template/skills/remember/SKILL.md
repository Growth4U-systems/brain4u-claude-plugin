# Remember

Confirm the content is durable, source it, classify privacy, deduplicate it and propose the smallest canonical change through the Brain write workflow.

If the candidate comes from MemSearch, treat its Claude Haiku summary as a pointer to evidence rather than as an approved fact. Review the relevant source context, remove transient or private material and never copy `.memsearch/` or its index into the repository. Create a pull request and wait for approval before treating the learning as canonical Brain memory.
