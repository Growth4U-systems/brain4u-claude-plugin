# Save session

Extract only durable decisions, reusable learnings and open questions. Remove secrets, raw dialogue, personal details and temporary state. Publish authorized, sourced decisions and learnings through the Brain write workflow; behavior and policy changes require a reviewed pull request.

MemSearch may provide a local Claude Haiku summary and links back to session context. Use them only to identify candidate learnings. Verify the evidence, preserve useful provenance and leave all `.memsearch/` files and index data outside git. Memory becomes canonical only after publication is verified or the required human review passes.
