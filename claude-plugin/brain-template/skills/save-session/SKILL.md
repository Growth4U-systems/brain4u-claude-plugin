# Save session

Extract only durable decisions, reusable learnings and open questions. Remove secrets, raw dialogue, personal details and temporary state. Create a pull request rather than writing directly to `main`.

MemSearch may provide a local Claude Haiku summary and links back to session context. Use them only to identify candidate learnings. Verify the evidence, preserve useful provenance and leave all `.memsearch/` files and index data outside git. Nothing becomes Brain memory until the pull request is reviewed and approved.
