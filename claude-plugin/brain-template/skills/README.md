# Skills

Skills are explicit, reusable workflows. Keep memory skills small and separate from domain-specific business knowledge.

MemSearch provides local episodic recall for Claude Code. Its files and semantic index are not Brain skills and must remain outside git. Use `save-session` to distill a session and `remember` to turn an approved fact, decision or learning into the smallest reviewable Brain proposal. Canonical memory changes only through a pull request.

Hermes uses the skills stored in the Brain and reads its durable Markdown. It does not query the MemSearch index on the user's computer.
